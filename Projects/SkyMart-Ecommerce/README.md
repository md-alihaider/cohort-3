# 🛒 SkyMart

A modern and responsive e-commerce web application built with **React**, **Tailwind CSS**, and **Context API**. SkyMart provides a clean shopping experience with authentication, product browsing, cart management, wishlist functionality, and a beautiful responsive UI.

## ✨ Features

### 🔐 Authentication

- User Registration
- User Login
- Logout
- Persistent Login using Local Storage

### 🛍️ Shopping Experience

- Browse Products
- Product Details Page
- Search Products
- Category Filtering
- Product Sorting
- Load More Products

### 🛒 Cart

- Add to Cart
- Remove from Cart
- Increase / Decrease Quantity
- Cart Drawer
- Dynamic Cart Total
- Checkout Toast
- Cart Persistence using Local Storage

### ❤️ Wishlist

- Add / Remove Wishlist
- Heart Toggle
- Local Storage Support
- Toast Notifications

### 📄 Additional Pages

- Home
- Shop
- Product Details
- About
- Login
- Register

### 🎨 UI Features

- Responsive Design
- Modern Dark Theme
- Toast Notifications
- Smooth Hover Effects
- Mobile Friendly

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/md-alihaider/SkyMart-Ecommerce.git
```

Go to the project directory

```bash
cd SkyMart-Ecommerce
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
