# 🍃 MongoDB Learning

A major part of my current backend learning journey is understanding MongoDB beyond basic CRUD operations.

Recently, I started learning **MongoDB Aggregation Pipelines** using MongoDB Compass and the `sample_mflix.movies` collection.

### Aggregation Stages Practiced

- `$match`
- `$sort`
- `$limit`
- `$skip`
- `$group`
- `$unwind`
- `$project`
- `$lookup`
- `$facet`

### Aggregation Concept

```text
MongoDB Collection
        ↓
     $match
        ↓
     $sort
        ↓
     $project
        ↓
     $lookup
        ↓
     $facet
        ↓
      Result
```

### Key Understanding

> The output of one aggregation stage becomes the input of the next stage.

I'm practicing aggregation through real-world case studies and MongoDB Compass to understand how data can be filtered, transformed, combined, and analyzed.
